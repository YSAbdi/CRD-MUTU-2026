# CRM Camp Resident MUTU

Laravel 11 + MySQL CRM untuk pengelolaan resident camp, tamu, kamar, booking, laporan, dan akses pengguna.

## Status implementasi

Repository menyediakan fondasi aplikasi yang dapat dipasang di project Laravel lokal: API Sanctum, role Superadmin, CRUD master data, pencegahan bentrok booking, dashboard dinamis, kalender API, ekspor PDF/XLSX, PWA shell, dark mode, queue migration, dan dokumentasi instalasi.

Ikuti [LOCAL_SETUP.md](LOCAL_SETUP.md) untuk instalasi dan troubleshooting. Jangan gunakan kredensial contoh pada lingkungan produksi.
